# Workforce Development Toolkit by HCAI

Four practical workflows for HR, talent acquisition, learning and development, and operations leaders. Each one turns a short conversation with Claude into a document you can use the same day.

## What's inside

| Skill | Ask Claude something like | You get |
| --- | --- | --- |
| Role skills framework | "Build a skills framework for a warehouse lead." | The skills a role needs, the level required for each, what mastery looks like, and an interview scorecard tied to those skills |
| Hiring wave plan | "We need 40 medical assistants for a new clinic opening March 2." | A plan worked back from the start date: requisitions, interview stages, pre-employment steps with owners, and readiness checkpoints |
| Onboarding plan | "Draft a 90-day onboarding plan for a new account manager." | A day-one, week-one, 30/60/90-day plan tied to the role's skills, with who owns each step and how readiness is checked |
| Underperformance diagnosis | "Our second shift keeps missing targets. Is it a training problem?" | A structured diagnosis that separates can't (skills), won't (motivation) and blocked (management, process, tools), with the questions and evidence to confirm it |

## How to use it

Describe your situation in plain words. Claude asks only for what it needs (the role, headcount, dates, what has been tried) and then produces the document. You can paste in an existing job description, org chart, or onboarding checklist to start from what you already have.

## Data

The plugin contains instructions only. It runs no code, connects to no servers, and sends nothing anywhere. Anything you share stays in your conversation with Claude.
